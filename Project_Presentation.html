CSI3025 - Application Development and Deployment Architecture

📋 Project Overview

  • Objective: Full-stack web application for managing employee leave requests with role-based access control
  • Architecture: RESTful API backend with Spring Boot and web-based frontend
  • Security: JWT-based authentication with encrypted passwords (BCrypt)
  • Database: MySQL for production, H2 in-memory for testing
  • Testing: Comprehensive JUnit 5 unit tests with Mockito
  • CI/CD: Jenkins pipeline for automated build, test, and deployment

🏗️ System Architecture

Backend (Spring Boot)

  • Controller Layer: REST API endpoints
  • Service Layer: Business logic & validation
  • Repository Layer: JPA data access
  • Security Layer: JWT filter & authentication
  • Exception Handler: Global error handling

Frontend (Web UI)

  • Login Page: JWT authentication
  • Employee Dashboard: Apply & view leaves
  • Manager Dashboard: Approve/reject requests
  • Admin Panel: User & leave type management
  • Reports: Leave history & analytics

✨ Key Features

🔐 Role-Based Access

Three roles: Employee, Manager, Admin with specific permissions and workflow controls

📝 Leave Application

Employees apply for leave with automatic balance checking and date validation

✅ Approval Workflow

Managers review, approve, or reject leave requests with comments

⚠️ Overlap Detection

System prevents overlapping leave dates for the same employee

💰 Balance Tracking

Real-time leave balance calculation with year-wise tracking

👥 User Management

Admin can register users, assign roles, and manage leave types

📊 Reports & History

Complete leave history with filters and date range queries

🧪 Automated Testing

JUnit 5 unit tests covering all business logic and validation

🗄️ Database Design

  • USERS: Employee details with role (Employee/Manager/Admin), email, encrypted password, department
  • LEAVE_TYPES: Configurable leave categories (Annual, Sick, Casual, Maternity, Paternity) with max days per year
  • LEAVE_BALANCES: Track total, used, and remaining days for each employee per leave type and year
  • LEAVE_REQUESTS: Leave applications with status (Pending/Approved/Rejected/Cancelled), dates, reason, and reviewer comments
  • Relationships: Foreign keys linking users to their leave balances and requests, maintaining referential integrity

🔒 Security & Authentication

  • JWT Tokens: Stateless authentication with HMAC-SHA256 signed tokens, 24-hour expiration
  • Password Encryption: BCrypt hashing with salt for secure password storage
  • Role-Based Authorization: Spring Security @PreAuthorize annotations on endpoints
  • Security Filter Chain: Custom JWT filter validates token on every request before controller access
  • CORS Configuration: Controlled cross-origin access with whitelisted domains
  • Session Management: Stateless sessions (no cookies) - pure REST API design

🧪 Testing & Deployment

Automated Testing

  • Unit Tests: JUnit 5 with Mockito for service layer
  • Test Coverage: Business logic validation, overlap checks, balance calculations
  • Mock Database: H2 in-memory for fast test execution
  • CI Integration: Tests run on every commit

Jenkins CI/CD Pipeline

  • Build: Maven compile with dependency resolution
  • Test: Execute JUnit test suite
  • Package: Generate executable JAR artifact
  • Deploy: Automated deployment to staging/production
